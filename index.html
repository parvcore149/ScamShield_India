How it works

1) Rules check for known scam patterns and inspect URL structure. 2) A local open-weight model (Gemma via Ollama) gives a second opinion. 3) We show both separately. Links are never opened.

Privacy

Messages are analysed on this computer, sent only to your local Ollama, and are not stored or logged. No external requests are made. If you deploy this on a remote server, messages will travel to that server. Never enter real passwords or OTPs.

Limitations: automated analysis can be wrong. When in doubt, contact the organisation directly, or report fraud at cybercrime.gov.in / 1930.
