
# Contributing to ScamShield India

Thank you for your interest in contributing to ScamShield India!

## How to Contribute

You can help improve this project by:

- Reporting bugs and suggesting improvements.
- Improving documentation and setup instructions.
- Adding useful scam-detection rules.
- Improving URL validation and error handling.
- Writing tests for existing functionality.

## Getting Started

1. Read the README.md file to understand the project.
2. Set up the project locally by following the installation instructions.
3. Test your changes before submitting them.
4. Describe clearly what you changed and why.

## Guidelines

- Keep changes focused and easy to review.
- Write clear, readable Python code.
- Add tests for new functionality where appropriate.
- Never commit API keys, passwords, or other secrets.
- Do not claim that a message is definitely a scam based only on a heuristic result.

## Reporting Bugs

When reporting a bug, include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected and actual behavior.
- Relevant error messages, without personal or sensitive data.

## Code of Conduct

Be respectful, constructive, and welcoming to everyone contributing to the project.

Thank you for helping make ScamShield India better!
